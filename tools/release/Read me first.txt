KALEIDOBOX
==========

Kaleidobox is a live music rig: sampler, looper, drum machine, synths, vocoder and a
song builder, all in one window. It runs as an app, and inside Logic as an instrument.

THE EASY WAY TO INSTALL (recommended)
-------------------------------------
1. Open Terminal (press Cmd+Space, type Terminal, press Return).
2. Paste this line and press Return:

   /bin/bash -c "$(curl -fsSL https://github.com/colinblackshear-cell/crate/releases/latest/download/install.sh)"

That installs the app, the Logic plugin and the VST3, with no security warnings.

OR, BY HAND FROM THIS WINDOW
----------------------------
1. Drag Kaleidobox.app onto the Applications folder.
2. Open it. The Mac says it can't check it. Click Done (or OK).
3. Open System Settings > Privacy & Security, scroll down, and click "Open Anyway"
   next to Kaleidobox. Open it again and click Open. You only do this once.

For Logic, drag Kaleidobox.component into
   your home folder > Library > Audio > Plug-Ins > Components
(In Finder use Go > Go to Folder... and paste ~/Library/Audio/Plug-Ins/Components )
Then do the same "Open Anyway" step if Logic says it can't use it.

Why the warning? Kaleidobox is made by a friend, not bought from a store, so it isn't
registered with Apple. It's safe; the Mac is just being careful.

IN LOGIC
--------
Make a Software Instrument track and pick
   AU Instruments > Colin Blackshear > Kaleidobox

The first time it uses your mic, the Mac asks. Click Allow.
