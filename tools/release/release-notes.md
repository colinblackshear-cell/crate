**Kaleidobox {{VERSION}}** for Mac (macOS 11 or newer, Intel or Apple silicon).

### Install

Open **Terminal** (Cmd+Space, type Terminal, press Return), paste this line and press Return:

```
/bin/bash -c "$(curl -fsSL https://github.com/colinblackshear-cell/crate/releases/latest/download/install.sh)"
```

It installs the app, the Logic plugin (AU) and the VST3, with no security warnings.

Prefer to drag it yourself? Download **Kaleidobox-mac.dmg** below and follow *Read me first*
inside it. The step-by-step page with pictures is at
https://colinblackshear-cell.github.io/crate/get/

### In Logic

Software Instrument track > AU Instruments > Colin Blackshear > **Kaleidobox**.
